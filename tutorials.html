Tutorials and Datasets

Writeups that apply data science methods to language data and other public-interest problems, plus links to datasets those projects used or that I have collected.

Tutorials

  • Duolingo Language Difficulty Analysis

    Language: R

    Analysis of Duolingo learner performance to compare relative difficulty among common languages for English-speaking users. Uses multiple regression and LMER.

    Notebook | GitHub

  • Reddit Sentiment Comparison

    Language: Python

    Sentiment comparison tool to quantify how different Reddit communities react to the same entertainment topic. Uses PRAW, pandas, and scikit-learn (TF–IDF, Naive Bayes sentiment classification, LDA topic modeling), with seaborn and matplotlib.

    Notebook | GitHub

  • Critical Role Transcript Explorer

    Language: Python

    Interactive dashboard for exploring language patterns in Critical Role transcripts, with phrase-level and character-level comparisons. Uses pandas, Plotly, and Dash.

    Notebook | GitHub

  • CaseGuide (traffic court outcomes)

    Language: Python

    Analysis of civil-traffic court records (Florida county, FOIA) to explore how case context and demographics relate to outcomes when people contest speeding tickets. Random forest and XGBoost multiclass models, calibration, and Plotly visualizations.

    Notebook

Datasets

Public releases and sources referenced in the tutorials above (and related or just cool datasets I've bookmarked).

  • Duolingo dataset (half-life regression) — public data and code for Settles & Meeder (ACL 2016); half-life regression for spaced repetition.
  • Duolingo (EMNLP dataset) — 2018 shared task on second language acquisition modeling (SLAM); token-level learner data with English, Spanish, and French tracks (BEA / NAACL-HLT 2018).
  • EF-Cambridge Open Language Database (EFCAMDAT) — large open-access corpus of L2 English learner essays with CEFR-style levels; access via application (academic affiliation; distribution through Google Drive after approval).
  • Critical Role transcripts — community episode transcripts (edited for length and clarity; see their site for caveats).
  • FIREBALL (D&D actual-play) — ~25k Discord sessions of real Dungeons & Dragons play via the Avrae bot, with aligned dialogue, executable commands, and ground-truth game state (Zhu et al.; PDF describes data and NLG / utterance-to-command tasks).
  • Tatoeba multilingual sentence corpus — large collection of example sentences and translation links (CC BY / CC0 depending on export); weekly dumps and custom sentence-pair exports.
